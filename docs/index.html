How it works

The whole trade, one step at a time

Each step reads the file the previous one wrote. Click a step. Dashed steps are gates: nothing moves past them without a pass.

Safety model

Three gates stand between an idea and an order

The pipeline can research and calculate freely. Only the last step can touch a broker, and only through all three gates, every time, for every order.

Risk PASS

/trader-risk checks this exact order against your stop, max loss, reward to risk, daily loss, trade count and entry window. BLOCK ends the trade.

Your typed yes

You see the ticket in plain words, with the max loss at the stop, and type yes for that one order. No yes, no order.

Your click

Claude's own Allow once / Deny card appears because the broker tool is set to Needs approval. A second human check.

Also: paper account by default, keys only in environment variables, web pages and filings treated as data that can never authorize a trade, and a stop is a plan, not a guarantee. Not financial advice. Most people who day trade lose money.

Get started

Install in three steps

Needs Python 3.11+ and Claude Code. Everything is local; the installer backs up your Claude config first.

  1. Install

    Copies the 12 skills, builds two Python environments (the packages pin conflicting dependencies) and registers the Vibe-Trading MCP server.

    python install.py

  2. Set your keys as environment variables

    Never paste keys into chat. One LLM key for TradingAgents, plus Alpaca paper keys for the broker step. Reopen the terminal after.

    setx ANTHROPIC_API_KEY "..."; setx ALPACA_API_KEY "PK..."; setx ALPACA_SECRET_KEY "..."

  3. Check, restart, trade on paper

    The doctor prints OK, WARN or FAIL for each piece and never shows key values. Restart Claude Code, then ask.

    python scripts/doctor.py

Set your limits by copying config.example.json to trader/config.json. For the broker, add Alpaca's official MCP server in paper mode; /trader-broker walks you through it.

Questions

FAQ

Does it trade real money?

No, not by default. The config ships with "paper": true and Alpaca's server defaults to the paper account. Going live is a deliberate change you make yourself, and every order still needs the three gates.

Can Claude place a trade on its own?

No. Only /trader-broker can lead to an order, only after a risk PASS for that exact order, your typed yes, and your click on Claude's permission card.

Why two Python environments?

TradingAgents and Vibe-Trading pin conflicting versions of shared libraries, so pip cannot install both together. Each gets its own environment.

Does it work with $60?

Yes, with fractional shares and a small max loss, which is what the default config sets. Costs and spreads matter more at this size, so treat it as a learning account.

How good are the predictions?

There are none. The Time Machine is a simulation built from a stock's recent bars, and backtests describe the past. Coin-flip odds mean pass. Under about 30 historical trades is an anecdote.

Where does the data come from?

Free, unofficial sources: Yahoo Finance charts, Nasdaq Trader symbol lists, SEC EDGAR and the House Clerk. They can lag or rate-limit. Verify price-critical numbers with your broker.

Not financial advice. This is software that reads public data and does arithmetic. It cannot see the future and does not know your situation. Most people who day trade lose money. Talk to a licensed professional if you need advice.
